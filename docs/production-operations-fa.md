# راهنمای عملیات روزمره HRM

- اصلاح اطلاعات غیرسازمانی از «ویرایش پرسنل» انجام می‌شود.
- تغییر پست/واحد/محل خدمت/وضعیت سازمانی فقط از «ثبت جابه‌جایی» انجام شود.
- خروج از خدمت یا بازنشستگی به‌عنوان تغییر وضعیت ثبت شود؛ Hard Delete برای رکوردهای واقعی توصیه نمی‌شود.
- Backup خودکار روزانه است؛ Super Admin باید وضعیت آخرین Backup را کنترل کند.
- Restore فقط توسط Super Admin و پس از Backup ایمنی انجام شود.
- فایل‌های Diagnostics برای پشتیبانی طراحی شده‌اند و نباید Database، Credential یا PII خام داشته باشند.
- قبل از هر Upgrade، Backup سالم و قابل Restore الزامی است.
