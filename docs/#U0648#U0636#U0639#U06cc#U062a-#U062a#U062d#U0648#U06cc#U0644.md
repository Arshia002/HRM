# وضعیت تحویل

## تأییدشده در محیط فعلی

- ساختار و سلامت دیتابیس SQLite
- شمارش ۱۳۵۶ پرسنل و ۵۳ صفحه چارت
- خالی بودن حساب‌ها و نشست‌ها در seed
- ورود، قفل حساب، تغییر اجباری رمز و نقش‌ها
- API سلامت، ورود و دریافت داده
- ویرایش همراه کنترل نسخه و تشخیص تعارض
- پنج ویرایش هم‌زمان روی رکوردهای مستقل
- زنجیره ممیزی، change feed، ویجت و ویرایش چارت
- compile شدن همه فایل‌های Python
- نبود فایل EXE/DLL/MSI قدیمی در سورس
- TLS واقعی و pinning اثرانگشت با گواهی تولیدشده
- migration نسخه‌دار و کنترل checksum
- MFA، کد بازیابی و ثبت تلاش‌های ناموفق
- گردش کار، اعلان و ریزدسترسی
- پشتیبان، integrity check و restore با safety copy
- پنج کلاینت API هم‌زمان
- سازنده Windows نسخه ۱۶ از نظر AST و مسیرهای build
- حذف PowerShell از لانچر یک‌کلیکی و ابزار عیب‌یابی نصب‌شده
- ثبت مرحله شکست در دو لاگ پایدار
- جداسازی AppId، پوشه ProgramData، دیتابیس و Windows Service از نسل‌های قبلی
- رد دیتابیس ناسازگار پیش از هرگونه تغییر
- fail-fast نصب و آزمون واقعی TLS health پیش از اعلام موفقیت

## نیازمند اجرای پذیرش روی Windows

خود فایل Setup باید روی Windows x64 طبق `docs/راهنمای-ساخت.md` ساخته و سپس روی Windows 10/11 و Windows Server 2019/2022 آزمایش شود. Workflow ویندوز شامل build، نصب silent، Service، TLS health و integrity دیتابیس است. محیط تولید این بسته Linux است و توان اجرای Windows Service یا Inno Setup را ندارد؛ بنابراین باینری فقط پس از عبور از Windows CI یا تست شما تأیید می‌شود.

این تفکیک عمدی است تا هیچ Setup آزمایش‌نشده‌ای با عنوان نسخه نهایی تحویل نشود.
