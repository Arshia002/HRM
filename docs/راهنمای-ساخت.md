# ساخت فایل نصب Windows

## ابزارها

- Windows 10/11 یا Windows Server 2019/2022 نسخه ۶۴ بیتی
- Python 3.11 x64
- Inno Setup 6

## فرمان ساخت

روش ساده: سورس را کامل در Desktop یا مسیر قابل‌نوشتن مانند `C:\HRM-Kermanshah-0.1.0-alpha.1` استخراج و روی `BUILD-SETUP.cmd` دوبار کلیک کنید. لانچر به PowerShell وابسته نیست و ابزارهای build را فقط روی رایانه سازنده آماده می‌کند. برای استقرار اداره فقط Setup مستقیمِ تأییدشده تحویل می‌شود.

روش دستی از ریشه پروژه:

```cmd
py -3.11 build\windows\build_windows.py
```

اسکریپت محیط مجزا می‌سازد، وابستگی‌های build را نصب می‌کند، همه آزمون‌ها را اجرا می‌کند، سه EXE تازه تولید می‌کند و در پایان Setup را می‌سازد. هیچ فایل اجرایی آماده یا قدیمی در ورودی build وجود ندارد.

اگر ساخت خطا دهد، پنجره پس از نمایش علت باز می‌ماند. برای عیب‌یابی از این دو فایل استفاده کنید:

```text
build-setup-bootstrap.log
build-output\build.log
```

خروجی مورد انتظار:

```text
build-output\installer\HRM-Setup-x64.exe
build-output\installer\HRM-Setup-x64.exe.sha256
build-output\installer\build-manifest.json
build-output\installer\dependencies.txt
```

`build-manifest.json` نسخه محصول، Commit سازنده، نوع Seed، مشخصات محیط و SHA-256 همه خروجی‌ها را ثبت می‌کند. فایل `dependencies.txt` نیز نسخه دقیق وابستگی‌های نصب‌شده در همان Build را نگه می‌دارد.

## امضای دیجیتال

قبل از تحویل سازمانی، EXEهای داخلی و Setup باید با گواهی Code Signing شرکت امضا شوند. امضای دیجیتال در این سورس قرار نمی‌گیرد چون کلید خصوصی باید فقط در زیرساخت امن شرکت نگهداری شود.

## کنترل پذیرش روی Windows

1. نصب کامل روی ماشین تمیز.
2. کنترل ساخته‌شدن Desktop shortcut.
3. کنترل Running بودن `HRMCentralService` پس از restart.
4. ورود با رمز یک‌بارمصرف و اجبار تغییر رمز.
5. نصب شش کلاینت و مشاهده تغییرات مشترک.
6. تست تعارض با ویرایش هم‌زمان یک رکورد.
7. ساخت پشتیبان و اجرای `PRAGMA integrity_check` روی نسخه پشتیبان.
8. Uninstall و اطمینان از حفظ داده‌های `ProgramData`.
9. تأیید اثرانگشت TLS در ورود نخست و رد گواهی با fingerprint متفاوت.
10. restart سیستم و کنترل سرویس، backup scheduler و لاگ JSON.
11. اجرای نصب مجدد روی همان نسخه و اطمینان از حفظ دیتابیس و حساب مالک اولیه.
12. کنترل اینکه فایل Seed پس از نصب داخل `Program Files` باقی نمانده باشد.

Setup تولیدشده برای نصب روی سیستم مقصد به Python، Qt، pip، winget، PowerShell، مرورگر یا اینترنت وابسته نیست. این ابزارها فقط در مرحله ساخت استفاده می‌شوند و در EXE نهایی runtimeهای لازم بسته‌بندی شده‌اند.
