# وضعیت Baseline

## موجود در نسخه 0.1.0-alpha.2

- هستهٔ کلاینت بومی Qt و سرویس مرکزی شبکه داخلی
- احراز هویت، نقش‌ها، ریزدسترسی، MFA و قفل حساب
- TLS و pinning اثرانگشت گواهی
- کنترل تعارض با `row_version`، ممیزی زنجیره‌ای و `change_feed`
- مدیریت پرسنل، چارت، داشبورد، گردش کار، اعلان و پشتیبان
- تست هم‌زمانی شش مدیر با حساب‌های مجزا
- Builder ویندوز، سه EXE مستقل و Inno Setup آفلاین
- جداسازی Seed از باینری‌ها و تزریق آن فقط در مرحلهٔ ساخت Setup
- دیتای ساختگی مستقل برای آزمون‌های CI

## دادهٔ واقعی

داده‌های واقعی ۱۳۵۶ نفر و چارت ۵۳ صفحه‌ای خارج از Repository تحلیل و تطبیق داده شده‌اند. آن فایل‌ها به‌دلیل محرمانگی در Git یا Artifact عمومی قرار نمی‌گیرند. Seed نهایی باید در محیط کنترل‌شده ساخته و با گزینهٔ `--seed` به Builder داده شود.

## موارد باقی‌مانده تا نسخه عملیاتی

- بازطراحی کامل UI/UX بر اساس Dashboard پکیج دوم
- تکمیل مدل جزئیات پرسنلی و نگاشت تمام ستون‌های فایل‌های رسمی، شرکتی، حجمی و پیمانکاری
- تعیین تکلیف مغایرت‌های داده و اختلاف یک پست چارت با تأیید مالک داده
- اجرای Build و آزمون نصب روی Windows CI
- تست پذیرش روی سرور و شش رایانهٔ واقعی شبکه داخلی
- دریافت و اعمال گواهی Code Signing و در صورت وجود، گواهی CA داخلی شرکت

تا عبور موفق از این مراحل، هیچ Setup با عنوان نسخه نهایی سازمانی منتشر نمی‌شود.
