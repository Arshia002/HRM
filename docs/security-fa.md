# مدل امنیت

- رمزها با PBKDF2-HMAC-SHA256، salt تصادفی و ۶۰۰٬۰۰۰ تکرار ذخیره می‌شوند.
- token نشست به‌صورت خام در دیتابیس ذخیره نمی‌شود؛ فقط SHA-256 آن ثبت می‌شود.
- نشست ۱۰ ساعت اعتبار دارد و خروج آن را باطل می‌کند.
- پس از پنج تلاش ناموفق، حساب ۱۵ دقیقه قفل می‌شود.
- مجوزها روی سرور کنترل می‌شوند و پنهان‌کردن دکمه در کلاینت مبنای امنیت نیست.
- هر تغییر با کاربر، زمان، قبل/بعد و زنجیره هش ثبت می‌شود.
- `row_version` مانع lost update بین مدیران می‌شود.
- دیتابیس به هیچ Share شبکه‌ای داده نمی‌شود و فقط سرویس مرکزی آن را باز می‌کند.
- رمز اولیه در سورس و دیتاست وجود ندارد و هنگام راه‌اندازی تولید می‌شود.
- TLS در نصب جدید پیش‌فرض است و کلاینت اثرانگشت SHA-256 گواهی را pin می‌کند.
- ورود دومرحله‌ای TOTP و هشت کد بازیابی یک‌بارمصرف در دسترس است.
- Secret مربوط به MFA با کلید محلی جدا از دیتابیس رمز می‌شود.
- نقش‌ها با ریزدسترسی allow/deny برای هر کاربر قابل محدودسازی هستند.
- لاگ عملیاتی JSON با چرخش حجم و نگهداری محدود ثبت می‌شود.

برای محیط عملیاتی نهایی، گواهی self-signed آزمایشی با گواهی CA داخلی سازمان جایگزین، Setup با گواهی Code Signing امضا و پوشه پشتیبان به مقصد دوم منتقل شود.
