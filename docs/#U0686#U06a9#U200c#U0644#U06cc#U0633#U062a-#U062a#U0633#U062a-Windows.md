# چک‌لیست تست کاربر روی Windows

## ساخت و نصب

1. سورس را کامل روی Desktop یا `C:\SazmanHR-Enterprise-16.0.7` Extract کنید؛ از داخل ZIP یا `Program Files` اجرا نکنید.
2. `BUILD-SETUP.cmd` را عادی اجرا کنید و تا پیام موفقیت صبر کنید؛ این مسیر PowerShell را اجرا نمی‌کند.
3. پس از build موفق، Setup خودکار باز می‌شود؛ درخواست UAC را تأیید کنید.
4. حالت «سرور مرکزی و کلاینت مدیریت» را انتخاب کنید.
5. پس از نصب، آیکون SazmanHR باید روی Desktop باشد.

## ورود و امنیت

1. فایل `C:\ProgramData\SazmanHR-Enterprise\FIRST_LOGIN.txt` را باز کنید.
2. برنامه را اجرا کنید و اثرانگشت TLS نمایش‌داده‌شده را با فایل مقایسه کنید.
3. با `arshia.shahbazi` و رمز یک‌بارمصرف وارد شوید.
4. رمز جدید قوی تعیین کنید؛ فایل FIRST_LOGIN باید حذف شود.
5. از بخش مدیریت، MFA را فعال و کدهای بازیابی را خارج از سیستم نگهداری کنید.

## عملکرد

1. جستجو در ۱۳۵۶ پرسنل را کنترل کنید.
2. یک رکورد آزمایشی را ویرایش و سپس مقدار قبلی را برگردانید.
3. جابه‌جایی صفحه/گره چارت فرد را آزمایش کنید.
4. یک ویجت داشبورد بسازید، ویرایش و حذف کنید.
5. یک Workflow بسازید و وضعیت آن را تغییر دهید.
6. پشتیبان فوری بسازید و بخش پایش را بررسی کنید.

## شبکه

روی کلاینت دوم حالت «فقط کلاینت» را نصب و آدرس `https://IP-SERVER:8765` را وارد کنید. تغییر انجام‌شده در یک سیستم باید ظرف چند ثانیه در سیستم دیگر دیده شود. برای آزمون کامل همین کار با پنج حساب جداگانه انجام شود.

## گزارش نتیجه

در صورت خطا، رمز، فایل FIRST_LOGIN و دیتابیس را ارسال نکنید. فقط این موارد را بفرستید:

- تصویر خطا
- `build-setup-bootstrap.log`
- `build-output\build.log`
- `build-output\installer\install-test.log`
- خروجی `Get-Service SazmanHREnterpriseCentral`
- فایل‌های `C:\ProgramData\SazmanHR-Enterprise\logs\server.jsonl*`
- فایل `C:\ProgramData\SazmanHR-Enterprise\logs\setup-server.log`
- نسخه Windows و مرحله‌ای که خطا رخ داده است
