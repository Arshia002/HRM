# HRM v1.0.0-rc.1 — کاندید نهایی استقرار سازمانی

این نسخه آخرین کاندید قبل از تأیید پایلوت واقعی است و هنوز Tag نهایی `v1.0.0` نیست.

## پروفایل استقرار مصوب

- Windows Server 2022، ترجیحاً VM/Server اختصاصی
- پیشنهاد منابع: 8 Core، 32 GB RAM، 1 TB SSD/NVMe، شبکه 1Gbps
- بدون وابستگی به اینترنت؛ ارتباط فقط در LAN داخلی شرکت
- IP داخلی ثابت و DNS داخلی
- 6 کاربر منابع انسانی: 2 Super Admin و 4 HR Admin
- حداکثر برآورد همزمان: 6 تا 7 کاربر
- شهرستان‌ها در فاز فعلی متصل نمی‌شوند

## کنترل تغییرات پرسنلی

تغییر واحد، پست، محل خدمت و وضعیت سازمانی از Edit عادی انجام نمی‌شود و باید از گردش کار جابه‌جایی ثبت شود.
Assignment قبلی بسته و نگهداری می‌شود، Assignment جدید با تاریخ اجرا ایجاد می‌شود و حکم، علت، قبل/بعد، کاربر ثبت‌کننده و Audit باقی می‌ماند.

## دسترسی‌ها

HR Admin: مشاهده/ویرایش روزمره، جابه‌جایی، گزارش و Backup.
Super Admin: همه موارد HR Admin به‌اضافه مدیریت کاربران و Permission، Restore، Hard Delete، تنظیمات حساس و ابطال آخرین جابه‌جایی.

## Backup

Backup زمان‌بندی‌شده پیش‌فرض هر 24 ساعت با نگهداری 30 نسخه محلی اجرا می‌شود.
`backup_secondary_dir` در `server.json` می‌تواند توسط IT به NAS/File Server/Storage سازمانی اشاره کند. مسیر ثانویه در Diagnostics عمومی افشا نمی‌شود.

## شروط Promotion به v1.0.0

1. GitHub Windows و Linux هر دو سبز.
2. Upgrade واقعی v0.8.0-rc.1 به این نسخه سبز.
3. پایلوت واقعی 1 Server + 6 Client بدون Data Loss، Security Blocker یا Critical Bug.
4. مقصد Backup ثانویه توسط IT تعیین و Restore آزمایشی شود.
5. وضعیت Code Signing مشخص شود. اگر Certificate سازمانی وجود دارد، همان Artifact Release باید با Pipeline امضاشده ساخته و تست شود.
