# داده‌های HRM

این پوشه فقط قرارداد مسیر داده را نگهداری می‌کند. هیچ دادهٔ واقعی یا دیتابیس تولیدی در Git قرار نمی‌گیرد.

- `seed/`: ورودی Build محلی؛ فایل‌های SQLite آن Ignore می‌شوند.
- `private/`: ورودی‌های خام و کنترل‌شده؛ کل پوشه Ignore می‌شود.
- `export/`: خروجی‌های موقت مهاجرت؛ کل پوشه Ignore می‌شود.

برای ساخت دیتای آزمون از `python tools/create_demo_seed.py` استفاده کنید. برای Build نهایی، Seed خصوصی را با `--seed` به Builder بدهید.
